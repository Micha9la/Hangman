Hangman

This project is a console-based implementation of the classic Hangman game written in C#.

The goal of the project was to strengthen my understanding of programming fundamentals by implementing the complete game logic independently.

The project was intentionally written without AI-generated code.

Features:
Console gameplay
Random word guessing
Input validation
Win/Loss detection
